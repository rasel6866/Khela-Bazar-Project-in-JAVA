
# 🎮 KhelaBazar — Java Game Store System

KhelaBazar is a feature-rich desktop application built with Java Swing and Object-Oriented Programming (OOP) concepts. Designed as a 2nd-semester university project, it simulates an online game distribution platform where users can explore, purchase, and manage the latest digital video games while offering administrators complete operational control.

---

## ✨ Key Features

* **User Marketplace:** Browse an updated catalog of video games with real-time detail views.
* **Seamless Purchase System:** Intuitive interface for selecting, purchasing, and managing game orders.
* **Admin Dashboard:** Centralized panel for managing game inventories, tracking user accounts, and updating store data.
* **Data Persistence:** File-handling capabilities to store and update transaction records and user accounts securely.
* **Modular Architecture:** Clean file organization separating interface components, core logic, and asset storage.

---

## 🛠️ Tech Stack & Folder Structure

* **Language:** Java (100%)
* **GUI Toolkit:** Java Swing / AWT


```

├── Data/         # Persistent storage for user records, game logs, and store data
├── Interfaces/   # Swing UI components, layout handlers, and user view screens
├── image/        # Asset graphics, icons, and cover artwork
└── Start.java    # Main application driver class

```
